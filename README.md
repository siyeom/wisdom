# Wisdom Theology

A single-page website for *Wisdom Theology*, a study of God's character told through four attributes — holiness, justice, compassion, and wisdom — traced from Genesis to the cross.

**By David Yeom**

## About the Book

*Wisdom Theology* argues that Christian ethics and doctrine begin not with a text but with a person: knowing God's character is what makes right and wrong knowable at all. The book unfolds in six chapters:

1. Introduction to Wisdom Theology
2. Good and Evil
3. First Attribute: Holiness
4. Second Attribute: Justice
5. Third Attribute: Compassion
6. Fourth Attribute: Wisdom
